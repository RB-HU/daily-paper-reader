## 摘要
许多经济决策问题，如生命周期消费储蓄和动态投资组合选择，是具有连续状态和动作的有限期随机控制问题。当状态维度较低时，可通过在网格上进行动态规划求解。网格成本随状态维度呈指数增长，即所谓的维度灾难，这促使我们用直接通过模拟优化的神经策略来替代价值函数网格。这类策略通常在催生它们的高维设定中研究，确切地说，正是在那里不存在参考解。因此，任何孤立的架构或训练选择的贡献都难以分离和诊断。我们因此退后一步，将架构和求解方法均作为研究对象。为此，我们考虑一个生命周期问题，其归一化状态空间维度足够低，可容许精确的动态规划解，用于评估。我们比较了四种架构。最简单的架构由单个以时间条件化的网络组成。接着，我们考虑在制度转换点上拼接的两个网络，然后是对每个日期用一个网络向后训练而冻结下游策略。最后，我们评估了每个日期架构的约束变体。将策略在时间上解耦使每个日期有一个简短、适定的目标，我们将其与方向主导优化相结合，该优化归一化掉梯度幅值。导致相似实现效用目标的架构，在是否尊重底层问题的经济学方面仍可能有所不同。因此，我们基于福利、无需求解的贝尔曼残差、形状约束以及得到的策略函数，对每种设计进行联合评估。

## Abstract
Many economic decision problems, lifecycle consumption-saving and dynamic portfolio choice, are finite-horizon stochastic control problems with continuous states and actions. When the state is low-dimensional these problems are solved by dynamic programming on a grid. The grid cost grows exponentially in the state dimension, known as the curse of dimensionality, which motivates replacing the value-function grid with a neural policy optimized directly through simulation. Such policies are usually studied in the high-dimensional settings that motivate them, precisely where no reference solution exists. So the contribution of any single architectural or training choice cannot be isolated and diagnosed. We therefore take a step back and treat both the architecture and the solution method as the objects of study. To this end, we consider a lifecycle problem with a sufficiently low-dimensional normalized state space to admit an accurate dynamic programming solution, which is used for evaluation. We compare four architectures. The simplest consists of a single time-conditioned network. We then consider two networks concatenated across the regime switch, followed by one network per date trained backward against frozen downstream policies. Finally, we evaluate a constrained variant of the per-date architecture. Decoupling the policy across time gives each date a short, well-posed objective, which we pair with direction-dominant optimization that normalizes away gradient magnitude. Architectures that lead to similar realized utility objective can nevertheless differ in whether they respect the underlying problem's economics. We therefore evaluate each design jointly based on welfare, a solution-free Bellman residual, shape restrictions, and the resulting policy functions.

- **研究动机**：文章“退后一步”，将策略架构和求解方法本身作为研究对象。在一个状态维度足够低、可求得精确 DP 参考解的生命周期问题中，系统比较不同神经网络策略架构的福利表现、策略准确性、贝尔曼残差和经济可解释性，从而为高维应用提供设计指南。

## 2. 论文提出的方法论

**核心思想**  
- 对非平稳生命周期问题（含工作期与退休期的制度转换），用可微的确定性神经网络直接输出消费和风险资产配置的策略，通过大量模拟路径的路径梯度（pathwise gradient）最大化期望终身效用。
- 关键在于**时间解耦程度**：从单一网络渐进到逐日期网络，将长时域优化拆分为短时域、适定的子问题，配合梯度归一化技巧，提高训练稳定性和精确度。

**四种架构详细说明**

- **架构 A —— 单一时间条件网络**
  - 一个多层感知机（MLP）处理特征 `(t/T, log(1+x)/log(1+x̄), 1[t ≥ t_R])`（2 层 128 单元 tanh），输出消费份额和风险份额，终端规则硬编码。
  - 直接优化整个生命期仿真总效用，使用全梯度回传。

- **架构 B —— 两制度拼接网络**
  - 工作期和退休期分别用两个较小的 MLP（各 2 层 64 单元）建模。退休网络先独自训练最大化退休阶段效用（随机初始现金抽自对数均匀分布），冻结后作为工作期网络的延续价值，工作期网络再训练全生命周期路径。
  - 相当于两阶段向后近似。

- **架构 C —— 完全向后逐日期网络**
  - 为每个决策日期建立独立的 MLP（2 层 32 单元，输入仅为归一化现金），共 80 个网络（终点由解析解给定）。从倒数第 2 期向前逐期训练，每个阶段冻结后面所有网络的参数，当前网络仅负责单步优化，延续值由冻结网络向前 rollout 的实现效用给出。
  - 使用**方向主导优化**：每个阶段梯度先归一化为单位范数，再用 AdamW 更新，克服不同日期回报幅值差异带来的尺度问题；同时采用对偶采样（antithetic pairs）降低梯度方差。

- **架构 D —— 形状约束向后网络**
  - 在架构 C 基础上，对每个阶段的损失增加**边际消费倾向（MPC）形状惩罚**：`λE[relu(-∂c/∂x)^2 + relu(∂c/∂x - 1)^2]`，强制 MPC ∈ [0,1] 的单调性约束。
  - 仅改动了损失函数，网络结构、可行性映射、训练流程与 C 完全一致，因此可隔离形状约束的影响。

**可行性保证**  
- 消费输出经过 sigmoid 变换并乘以现金‑手头金额同时保留下限，风险份额也经 sigmoid 控制于 [0,1]，策略天然满足可行域，优化问题无约束。

## 3. 实验设计

- **基准问题**：采用 Cocco、Gomes & Maenhout (2005) 的归一化生命周期消费‑投资组合选择模型，经过 CRRA 齐次性变换，归一化后状态仅为一维“现金‑按永久收入划分”（cash‑on‑hand）。问题含有 46 期工作期和 35 期退休期，退休时有确定性的养老金替代。
- **参考解**：使用细网格上的 DP 所求得的策略，作为“真值”衡量所有神经网络策略。
- **对比方法**：四种架构 A、B、C、D（上文所述），均未使用 DP 解进行训练。
- **评估指标**：
  - 福利：确定性等价消费损失（CE loss）、实现效用的差距、路径低于 DP 的比例及分位数差距。
  - 策略精度：在共享网格上对消费份额、风险份额的 MAE。
  - 无需求解诊断：采用贝尔曼残差（单步改进间隙，以 CE 百分比计），分别在统一网格和访问加权下衡量。
  - 经济形状：负 MPC 的网格单元数、非单调步骤数（单调性违反）。
  - 样本效率：将架构 C 和 D 的训练路径数从 200k 缩减至 100 再比较。

## 6. 论文的主要结论与发现

- **逐层加入向后归纳结构持续提升性能**：
  - 单一网络（A）已有相当表现，但存在退休期过度储蓄的偏向。
  - 两制度拆分（B）能挽回约 40% 的 CE 损失，但退休阶段尾部仍不够理想。
  - 完全向后逐日期网络（C）将 CE 损失降至 0.127%，消费份额误差从 0.055 降至 0.013，大幅降低低于 DP 的路径比例。
- **形状约束消除经济不合理行为**：架构 C 因逐日期解耦而导致较多负 MPC 单元（109 个，3.32%），而引入 MPC ∈ [0,1] 惩罚的 D 彻底消除负 MPC 和非单调步骤，且不影响福利水平。
- **形状约束提升样本效率**：训练路径极少（100 path/期）时，D 仍保持极低的 MPC 违反，且实现效用的截面离散度小于 C。
- **多维度诊断的必要性**：仅依赖实现效用会掩盖负 MPC 等结构缺陷；贝尔曼残差和形状诊断能补充大量信息，三者联合为无参考解的场景提供实用的检验框架。

## 7. 优点

- **可控对比**：在精确 DP 参考解下架构与训练技巧的单独贡献得以诊断，避免了高维黑盒的困境。
- **系统性的架构谱系**：从单网到双制度再到逐日期，构成清晰的解耦递进，清晰地显示出时间解耦的好处与代价。
- **训练稳定性设计**：方向主导更新归一化不同期回归尺度，对偶采样降方差，使得长时域下神经网络策略训练可行。
- **形状约束与可解释性**：将经济学理论中的 MPC 约束以软惩罚形式嵌入，既保持网络灵活性，又确保策略经济合理，且对福利几乎无损。
- **综合评估框架**：福利、无需求解贝尔曼残差、形状约束三者结合的评估方案，对未来高维神经策略的验证具有示范意义。
