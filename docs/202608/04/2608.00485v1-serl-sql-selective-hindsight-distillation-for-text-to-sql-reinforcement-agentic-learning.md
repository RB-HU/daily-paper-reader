## 摘要
近期的文本到SQL系统越来越多地依赖多轮交互、执行反馈和强化学习。然而，大多数现有方法仅将执行正确性作为轨迹级别的奖励，这对于识别导致成功或失败的SQL决策提供的指导有限。我们提出SERL-SQL，一个面向多轮文本到SQL智能体的选择性执行基强化学习框架。SERL-SQL采样在策略SQL交互轨迹，并使用仅用于训练的教师模型，通过执行反馈重新评分学生动作。由此产生的教师-学生似然差距被转换为有界的、带掩码的权重，仅在SQL和工具动作令牌上重新加权GRPO优势。这样，任务奖励保持优化方向，而执行事后分析提供局部化信用分配。在BIRD、Spider和跨领域基准上的实验表明，SERL-SQL达到了具有竞争力的性能，在BIRD-Dev上达到76.56%的执行准确率，在Spider-Test上达到89.92%。此外，我们基于奖励的选择策略紧密接近甲骨文最佳N个上限，并始终优于基于一致性的选择，表明SERL-SQL生成的高质量候选可以通过轻量级执行基奖励可靠地识别。我们的代码将在 https://github.com/Ffunkytao/SERL-SQL 发布。

## Abstract
Recent Text-to-SQL systems increasingly rely on multi-turn interaction, execution feedback, and reinforcement learning. However, most existing methods use execution correctness only as a trajectory-level reward, which provides limited guidance for identifying the SQL decisions responsible for success or failure. We propose SERL-SQL, a selective execution-grounded reinforcement learning framework for multi-turn Text-to-SQL agents. SERL-SQL samples on-policy SQL interaction trajectories and uses a training-only teacher to re-score student actions with execution feedback. The resulting teacher--student likelihood gap is converted into bounded, masked weights that reweight GRPO advantages only on SQL and tool-action tokens. In this way, task rewards preserve the optimization direction, while execution hindsight provides localized credit assignment. Experiments on BIRD, Spider, and cross-domain benchmarks show that SERL-SQL achieves competitive performance, reaching 76.56% execution accuracy on BIRD-Dev and 89.92% on Spider-Test. Moreover, our reward-based selection strategy closely approaches the oracle Best-of-N upper bound and consistently outperforms consistency-based selection, showing that SERL-SQL produces high-quality candidates that can be reliably identified by lightweight execution-grounded rewards. Our code will be released at https://github.com/Ffunkytao/SERL-SQL.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：当前多轮交互式Text-to-SQL智能体主要使用**轨迹级别的执行正确性奖励**进行强化学习（如GRPO）。这种粗粒度的奖励信号无法精细区分哪些SQL动作或中间决策真正导致了成功或失败，导致信用分配模糊，优化效率受限。
- **背景**：Text-to-SQL正从单次生成向**智能体式多轮交互**演进（包含schema grounding、生成、执行、验证、修正、选择），需要模型能利用执行反馈进行迭代修正。已有工作尝试使用执行反馈，但依然停留在轨迹级或步骤级，缺乏对可执行SQL决策的局部化、细粒度信用分配。
- **整体含义**：SERL-SQL提出一种**选择性执行反馈强化学习框架**，利用训练时教师模型对执行反馈的“事后分析”，生成有界的、带掩码的token级优势重加权，从而在保留任务奖励优化方向的同时，实现对SQL和工具动作token的精确信用分配，最终提升多轮SQL智能体的生成质量和候选可靠性。

### 2. 论文提出的方法论

- **核心思想**：将数据库执行反馈作为一种特权信息（仅训练时可用），通过**在策略教师模型重新评分学生动作**，将师生似然差距转化为token级权重，并仅作用于可执行SQL及工具动作token上，实现选择性信用分配。
- **关键技术细节**：
  - **Schema Grounding**：先通过离线向量索引和在线值检索，结合推理链接和值链接，从全量schema中筛选出紧凑、与问题相关的subset（含表、列、代表性值），作为后续所有策略rollout的共享上下文。
  - **多轮SQL智能体Rollout**：智能体在每次交互中生成推理+SQL动作，数据库返回执行结果（结果表、运行时错误、解析错误等），智能体可据此修正后续动作。每条轨迹的奖励由层次化验证器给出（有效且结果正确：+1；有效但错误：0；无效格式：-1）。
  - **选择性执行-事后教师（Selective Execution-Hindsight Teacher）**：
    - 对学生在某一步生成的可执行SQL token，教师模型以当前**执行观察**（如错误信息、空结果集）作为额外输入，计算其在该上下文下的对数概率。
    - 教师仅用于**重新评分**，不生成替代轨迹，不参与推理，训练时停止梯度。
    - 定义动作掩码 \(m_{t,i}\)：仅当token属于可执行SQL或工具动作时置1，否则置0。
  - **事后引导的优势重加权（Hindsight-Guided Advantage Reweighting）**：
    - 计算师生似然差 \(\Delta_{t,i} = \log\pi_T(·|\,c_{t}^{ex}) - \log\pi_\theta(·)\)。
    - 转换为有界、符号感知的权重因子 \(w_{t,i} = \text{clip}(\exp(\text{sgn}(A_n)\cdot \text{sg}[\Delta_{t,i}]), w_{\min}, w_{\max})\)，其中 \(A_n\) 为轨迹级GRPO优势。优势为正时，事后支持的token得到强化；优势为负时，事后不支持的token受到更强压制。
    - 有效权重 \(\bar{w}_{t,i} = (1 - m_{t,i}) + m_{t,i} w_{t,i}\)，非动作token保持原GRPO权重。
    - 引入衰减系数 \(\alpha_k\)，随着训练推进逐渐减少对事后信息的依赖，最终优势为 \(\tilde{A}_{t,i} = A_n [ (1-\alpha_k) + \alpha_k \bar{w}_{t,i}]\)。
    - 使用裁剪后的GRPO surrogate形式更新策略，整体目标仍由轨迹奖励决定方向，事后权重仅影响更新的**幅度与局部性**。
  - **推理时**仅使用学生策略，无需教师。

### 6. 论文的主要结论与发现

- SERL-SQL通过将执行反馈转换为局部化、奖励对齐的token级信用重加权，**显著提升了多轮Text-to-SQL智能体的性能**，在BIRD-Dev (76.56%)、Spider-Test (89.92%)等多个基准上取得领先或具竞争力结果，且仅用BIRD训练。

- 执行事后分析的有效性取决于**因果对齐（即时观察）和局部控制（动作掩码、符号感知、衰减）**，盲目扩大反馈上下文反而无益。
- 消融实验明确，**Schema Grounding**和**Execution Hindsight**是最关键的贡献点，且需精细的遮蔽与剪裁以避免信用扩散和特权信息偏差。

### 7. 优点：方法或实验设计上的亮点

- **创新性**：首次将执行反馈作为训练时特权上下文用于token级信用分配，既继承了GRPO的稳定方向，又提供了局部精细化控制，避免了简单模仿教师的泄漏与不稳定。
- **设计紧致**：通过动作掩码、符号感知权值、有界剪裁和逐步衰减，将事后信息严格限制在可执行token且与优势方向一致，机理清晰。
- **实验扎实**：多模型规模（7B/14B/32B）、多数据集、多组消融与分析实验，且与最新强基线全面比较，推理仅用BIRD训练数据仍表现出强泛化性。
- **工程鲁棒**：推理时剥离教师，部署与标准策略无异；且支持执行反馈的多轮恢复，降低格式错误和无效输出。
