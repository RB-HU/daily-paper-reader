## 摘要
强化学习（RL）搜索代理通常将检索建模为自由形式自然语言查询生成，并使用最终答案奖励优化多轮交互。当前研究主要通过更密集或更结构化的信用信号改进训练，但很少审视策略-环境接口处的检索是否被恰当形式化。我们在Search-R1训练期间观察到显著的检索别名现象：同一问题的不同轨迹持续生成不同的查询字符串，但其累积的证据集合逐渐重叠。我们称此现象为检索等价崩溃；在此状态下，轨迹在检索决策方面趋于效用等价，导致组内回报缺乏有效的检索对比。为解决此问题，我们提出Harness-G，一个重新设计该接口的图结构式检索框架。它将自由形式查询生成重新表述为有限动作选择：策略选择证据句子或实体，或选择回答，而环境构建菜单、追踪检索状态、验证并执行每个选择。此接口减少了语言别名，并使相同状态下的备选项可直接比较。基于此接口，我们引入结构化非短视信用（SNC），该方法使用一个冻结的答案评分器将所选动作与其备选项进行比较，并将下游增益分配给使之成为可能的早期动作。在六个问答基准上，Harness-G在两种评估模型规模下均取得最高平均F1分数，在1.5B参数下优于最强基线Graph-R1超过10.74分，在3B参数下优于3.98分。

## Abstract
Reinforcement learning (RL) search agents commonly model retrieval as free-form natural-language query generation and optimize multi-turn interactions using final-answer rewards. Current studies mainly improve training with denser or more structured credit signals, but rarely examine whether retrieval is properly formulated at the policy-environment interface. We observe pronounced retrieval aliasing during Search-R1 training: rollouts for the same question continue to generate distinct query strings, yet their accumulated evidence sets increasingly overlap. We call this phenomenon retrieval-equivalence collapse; in this regime, trajectories approach utility equivalence with respect to retrieval decisions, leaving within-group returns with little effective retrieval contrast. To address this problem, we propose Harness-G, a graph-structured retrieval framework that redesigns this interface. It reformulates free-form query generation as finite action selection: the policy selects an evidence sentence or entity, or chooses to answer, while the environment constructs the menu, tracks retrieval state, and validates and executes each choice. This interface reduces linguistic aliasing and makes same-state alternatives directly comparable. Building on this interface, we introduce Structured Non-myopic Credit (SNC), which uses a frozen answer scorer to compare the selected action with its alternatives and assigns downstream gains to the earlier actions that enabled them. Across six QA benchmarks, Harness-G achieves the highest average F1 at both evaluated model scales, outperforming the strongest baseline, Graph-R1, by 10.74 points at 1.5B and 3.98 points at 3B.

### 1. 论文的核心问题与整体含义

本研究聚焦于强化学习（RL）搜索代理中一个根本性的设计缺陷：**策略-环境接口处的检索定义不当**。

- **研究背景**：当前主流的RL搜索代理（如Search-R1）普遍采用“自由形式的自然语言查询生成”作为检索动作。代理在推理过程中自行生成查询，并基于最终答案的奖励（Outcome Reward）来优化完整的多轮交互轨迹。
- **核心问题：检索等价崩溃**：论文通过实证观察到，虽然代理针对同一问题能生成表面上千差万别的查询字符串（高查询形式多样性），但它们检索到的证据集合却高度重叠（低检索结果多样性）。随着训练进行，这种证据重叠导致不同轨迹在检索决策上趋于效用等价。论文将这种现象命名为**“检索等价崩溃”**。
- **问题影响**：这种崩溃严重破坏了GRPO（组相对策略优化）等主流优化器的学习信号。因为当组内轨迹的证据高度重合时，它们会获得几乎相同的回报，导致组内优势函数（Within-group Advantage）消失，优化器无法辨别哪个检索动作更好，从而产生了“虚假的探索”。其本质不在于奖励信号不够密集，而在于自由形式文本到检索结果的**多对一映射**在根本上抹除了检索决策的对比度。

### 2. 论文提出的方法论：Harness-G框架

为解决上述问题，论文提出了**Harness-G**，其核心思想是**将多跳检索从自由形式的查询生成，重构为有限、可验证的状态化导航**，并配套设计了新的信用分配机制。

- **核心思想与接口重新设计**：
    - **图结构式动作空间**：Harness-G不再让策略生成自然语言查询，而是将其行动空间限定为对证据句子或实体的有限选择。
    - **三部分图构建**：离线阶段，系统将语料库构建为一个轻量级的段落-句子-实体图，无需LLM参与，仅使用句子切分、实体识别和归一化。句子是最小证据单元，实体是跨句跳转的桥梁。
    - **可导航菜单环境**：在线阶段，环境根据当前状态暴露一个动态、去重的有限动作菜单。策略只能从中选择三种动作：
        1.  **Select (句子ID)**：将菜单中可见的某个句子提交为正式证据。
        2.  **Lookup (实体ID)**：选择一个实体作为检索目标，由环境（而非模型）根据当前已提交的证据和问题，确定性构造查询并检索该实体相关的缺失信息。
        3.  **Answer / Answer_With**：终止检索并生成答案，或选择某个句子作为最终证据并立即终止。
    - **设计属性**：此设计天然具备三个关键属性：
        - **有限性**：每一步的可行动作数量是有限的。
        - **可验证性**：动作的语义明确，无效动作会被环境直接屏蔽，而非事后惩罚。
        - **可预览性**：由于状态转移是确定性的，环境可以“只读预览”执行某个动作后会带来哪些新证据，而无需真实执行。

- **结构化非短视信用：**
    - 基于可预览性，论文提出了**结构化非短视信用（SNC）** ，它利用一个冻结的答案评分器（Frozen Answer Scorer）在训练时计算步骤级别的精细奖励，无需额外的代理采样。
    - **前沿相对优势**：对于一个信息获取动作，SNC会预览同一状态下其他可行的、同样类型的信息获取动作（前沿备选项），并用冻结评分器计算它们各自带来的边际信息增益。所选动作的信用，是其**自身信息增益与前沿海备选项平均增益的差值**。这迫使策略只有在所选动作显著优于同状态下的同类选择时，才能获得正向信用。
    - **结构化赋能信用**：为解决早期桥接动作（如只找到一个桥梁实体，但并未直接提升答案概率）在短期内收益为零的问题，SNC会记录动作间的“溯源依赖图”。它将后续动作（如利用桥梁实体找到最终答案）获得的高增益，沿依赖关系反向传播给使之成为可能的早期动作。

- **与GRPO的整合**：
    - 每条轨迹的最终优势 \(\hat{A}\) 由两部分相加组成：原始的GRPO结果归一化优势 \(\hat{A}^{out}\) 和经过缩放、裁剪的SNC步骤优势 \(\hat{A}^{SNC}\)，共同作用于策略梯度更新。

### 6. 主要结论与发现

论文得出了强有力的结论，证明检索接口和信用分配是两个正交且互补的改进维度。

- **显著性能提升**：Harness-G在两种模型规模下均取得了最高的平均F1。相比最强基线Graph-R1，在1.5B模型上提升**10.74分**，在3B模型上提升**3.98分**，小模型受益尤为明显。
- **接口与信用的协同作用**：
    - **接口是关键**：将自由查询替换为菜单接口，即使只使用结果奖励，也带来了巨大的性能飞跃（在MuSiQue上F1提升超35分），有效缓解了检索等价崩溃。
    - **SNC进一步增益**：在菜单接口之上，SNC通过解决同状态下的细微动作比较和非短视的远期奖励问题，进一步提升了多跳问答的分数。
    - **两者互补**：单独的密集信用（如IGPO）在自由查询下仍有很大残差，弥补不了接口带来的差距；而菜单+结果奖励则无法处理延迟回报。两者结合才达到最佳效果。
- **训练稳定性和交互效率**：Harness-G的训练过程稳定，避免了奖励崩溃，它能适应多种RL算法。虽然在训练后期平均交互轮数略多，但其产生的响应侧token更少，整体交互行为更高效。
- **强大的泛化能力**：在跨数据集和零样本领域迁移实验中，Harness-G的表现均显著优于Graph-R1，证明结构化导航学习的是一种可迁移的通用搜索策略，而非针对特定数据集的过拟合。

### 7. 优点

- **问题定义深刻**：“检索等价崩溃”现象的发现和命名，精准地指出了当前主流范式的固有问题，即对“动作”的定义有误。这是对领域认知的重要贡献。
- **方法论创新且优雅**：Harness-G的解决方案非常优雅。它不是增加一个复杂的模型来修正错误，而是通过**重新设计环境接口**，将从动作空间层面消除了“别名”问题。这使得整个问题变得更可控，体现了“好的设计比复杂的算法更重要”的理念。
- **可预览性驱动的精细信用**：SNC巧妙利用确定性环境和可预览性，无需任何额外的蒙特卡洛采样或训练独立的Critic模型，就实现了低方差、上下文相关且非短视的信用分配。这在计算效率上是巨大的优势。
- **经济性与实用性**：程序化、LLM-free的图构建和低计算开销，使得Harness-G相比依赖LLM抽取知识的GraphRAG系列方法，在成本和部署效率上具有巨大优势，非常实用。
- **实验论证极为扎实**：尤其是“转移匹配比较”的设计和详尽的消融实验，清晰、定量地解耦了各个组件的贡献，论证过程严谨，说服力强。

### 8. 不足与局限

- **动作空间的局限性与领域依赖**：菜单的生成高度依赖于底层的**实体识别（NER）** 管道。对于非标准实体（如化学分子式、产品型号）或不支持的语言，实体链接和菜单构建可能会失败，导致检索能力受限。论文也指出其为“纯文本”方法。
- **单跳与事实类任务增益有限**：跨域泛化实验揭示，Harness-G的增益主要在多跳推理场景中体现，在NQ、TriviaQA等事实检索/单跳任务上的优势相对较小（甚至有所下降）。这表明该方法特别适用于有明确推理链的任务，对于简单的“问-搜-答”模式，其结构化带来的好处可能被其约束所抵消。
- **对初始检索质量的依赖**：策略只能在环境提供的菜单内做选择。虽然菜单内的动作是明确的，但如果初始检索系统未能召回包含关键证据的候选句子，策略将无从选择，导致任务直接失败。论文中展示的失败案例也印证了这一点。
- **环境设计的黑箱性**：将查询构造、实体链接等工作完全封装在环境内部，虽然简化了策略的学习，但也意味着策略的学习效果受制于这些内部规则的预设。环境的检索、entity linking等策略的优化，与策略训练是脱节的，无法端到端优化。
- **答案生成与检索的分离**：最终生成器仅基于已提交的证据生成答案，而信用分配（SNC）则基于一个独立的冻结评分器评估所有观测到的信息。这导致信息获取、最终答案的选择和真实的答案生成过程之间存在潜在的对齐差距。
