## 摘要
AI智能体在每次运行的情节中都会遇到学习机会，却又几乎全部丢弃：部署时底层模型被冻结，因此一个今天解决了棘手请求的智能体，明天面对同样请求时又要从零开始。然而，日常运行本身已产生反馈，其形式包括结果判定和事后纠正。我们证明，当冻结模型与一个外部记忆相结合，该记忆将每个情节提炼成可检索的自然语言规则时，这种反馈是持续学习的充分信号。在τ-bench的银行领域，相较于在完整策略语料库上检索的静态RAG对照组，从一位结果判定中学习使单次尝试成功率提升至基线的1.6倍，而从纠正中学习提升至2.6倍，使基线从未解决的84个任务中的22个成功解决。这一结果覆盖了部署范围，在Mistral Large（有数据主权要求的组织可自行托管的开放权重模型）上测试，并在前沿模型Claude Sonnet 5上复现。积累的记忆亦可迁移：每个模型在读取对方构建的记忆存储后，均超越自身无记忆的基线。相关工具、协议和数据均已发布。

## Abstract
AI agents encounter learning opportunities in every episode they run, and discard nearly all of them: the underlying models are frozen at deployment, so an agent that resolves a difficult request today starts from zero when it recurs tomorrow. Yet ordinary operation already produces feedback, in the form of outcome verdicts and after-the-fact corrections. We show that this feedback is a sufficient signal for continual learning when the frozen model is paired with an external memory that distils each episode into retrievable natural-language rules. On the banking domain of $τ$-bench, against a static-RAG control retrieving over the complete policy corpus, learning from the one-bit outcome verdict lifts single-trial success to 1.6$\times$ the baseline, and learning from corrections to 2.6$\times$, converting 22 of the 84 tasks the baseline never solves. The result spans the deployment spectrum, measured on Mistral Large, an open-weights model that organisations with data sovereignty requirements can self-host, and replicated on a frontier model, Claude Sonnet 5. The accumulated memory also transfers: each model, reading the store built by the other, rises above its own no-memory baseline. The harness, protocol, and data are released.

### **2. 论文提出的方法论**

*   **核心思想:** 提出一种基于外部记忆的持续学习框架，作为冻结模型大脑（权重）的补充。这个外部记忆系统（Spark）负责存储、检索和维护从每次任务交互中萃取出的知识，从而实现无梯度的“在职学习”。

        1.  `memory_search`：在任务中根据当前情境检索相关洞察。
        2.  `memory_create`：在任务结束后贡献新的洞察。
        3.  `memory_enrich`：丰富现有洞察。
        4.  `memory_feedback`：报告检索到的洞察是否有用，形成一个“贡献-反馈”闭环。
    *   **知识生命周期管理：** Spark后端异步处理知识，包括安全过滤、质量把关、去重、冲突协调、衰减去重和合成（从相似洞察集群中抽象出更高级的洞察）。
*   **学习流程：**
    1.  **任务执行阶段（读路径）：** 智能体在对话中可主动调用`memory_search`来搜寻过往经验，结合常规的RAG（检索增强生成）来指导当前决策。记忆检索完全由智能体驱动。
    2.  **任务结束阶段（写路径）：** 智能体在单次任务结束后，会进入一个专门的反思阶段。根据接收到的反馈信号，它将本次经验提炼成一条“WHEN...THEN...”格式的简明规则，并以极低的数量存入记忆。

        *   **指导模式：** 在失败时，额外接收正确操作序列，可以将正确的规则写入记忆。

### **3. 实验设计**

*   **数据集/场景:** 在τ-bench的银行领域上进行测试。该领域要求智能体通过与模拟客户对话来处理复杂的银行业务，其核心挑战在于必须通过检索一个包含约700份政策文件的语料库来掌握业务规则。模型自带知识几乎无效，完美地模拟了现实世界中智能体依赖内部专有知识库的场景。
*   **基准对比方法:**
    *   **无记忆基线：** 标准的静态RAG设定，智能体可检索完整政策库，但在多次试验间不保留任何记忆。
    *   **经验：** 在基线基础上，智能体从单次任务的成功/失败判定（1比特信号）中学习。
    *   **指导：** 在基线基础上，智能体从成功/失败判定和失败任务的事后正确操作序列中学习。

### **6. 论文的主要结论与发现**

*   **部署反馈是充分的持续学习信号:** 仅凭1比特的结果判定，单次试验成功率即可提升至基线的1.6倍；加上事后修正，提升至基线的2.6倍，并将22个基线从未解决的任务成功转化。
*   **学习效应显著且可复现:** 学习曲线清晰可见：记忆条件与基线在第一次试验中持平，随着试验次数增加，记忆条件成功率持续上升，而基线保持不变。这一现象在Mistral Large和Claude Sonnet 5上均得到复现。

*   **不同反馈级别导致不同学习特性:** “经验”模式（仅1比特反馈）的“保持率”极高，但“转化率”有限；而“指导”模式（有修正）的转化能力远超前者，但因其更激进的规则泛化，有时会导致已验证的解法被覆盖（保持率相对较低）。

### **8. 不足与局限**

*   **实验范围有限:** 实验仅在τ-bench的银行领域进行。虽然有跨模型验证，但缺乏在更多类型任务（如代码、开放式对话）上的测试。论文本身也指出，未测量其对未见过的、全新任务类型的泛化能力。
