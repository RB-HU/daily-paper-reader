## 摘要
大语言模型智能体经常遇到相关但不同的任务，这些任务共享可重用的解决方案模式。然而，标准的智能体强化学习将任务视为独立的片段，而现有的技能学习方法要么关注单个任务的重复尝试，要么使用多阶段流水线，使提取、检索和执行相互纠缠。我们提出 SkillRise，一个统一的强化学习框架，用于跨任务学习技能。SkillRise 将相关实例组织成挑战性逐步增加的序列，并使用单一策略在任务求解与整理不断演化的技能文档之间交替，该文档直接传递给下一个任务。跨任务的解耦信用分配通过当前任务结果监督求解，通过折扣后的下游结果监督整理。在 ALFWorld、WebShop 和 ScienceWorld 上的实验表明，SkillRise 在对比方法中取得了最强的 Pass@1 性能，相较于最强基线的提升幅度在 2.3 至 8.5 个百分点之间。尽管在不同任务上训练，其学习到的整理策略在相同任务的重复尝试中仍然有效。进一步分析揭示了测试时跨任务的扩展性：即使每个任务只尝试一次，随着相关任务序列变长，性能也会提升。这一趋势表明 SkillRise 跨任务重用了可迁移技能，而非受益于对同一任务的重复采样。SkillRise 在保持强劲性能的同时，大幅降低了多阶段技能学习流水线的运行时间开销。这些结果共同为 LLM 智能体提供了一种简单高效的训练范式，使其能够跨任务提取、提炼和重用可迁移技能。

## Abstract
Large language model agents often encounter related yet distinct tasks that share reusable solution patterns. Yet standard agentic reinforcement learning treats tasks as independent episodes, while existing approaches to skill learning either focus on repeated attempts of one task or use pipelines with multiple stages that entangle extraction, retrieval, and execution. We introduce SkillRise, a unified reinforcement learning framework for learning skills across tasks. SkillRise organizes related instances into progressively challenging sequences and uses a single policy to alternate between task solving and curating an evolving skill document passed directly to the next task. Decoupled credit assignment across tasks supervises solving with the current task outcome and curation with discounted downstream outcomes. Experiments on ALFWorld, WebShop, and ScienceWorld show that SkillRise achieves the strongest Pass@1 performance among the compared methods, with gains over the strongest baseline ranging from 2.3 to 8.5 percentage points. Although trained across distinct tasks, its learned curation policy remains effective for repeated attempts on the same task. Further analysis reveals scaling at test time across tasks: performance improves with longer sequences of related tasks even when each task is attempted only once. This trend suggests that SkillRise reuses transferable skills across tasks rather than benefiting from repeated sampling of the same task. SkillRise further retains strong performance while substantially reducing the runtime overhead of skill learning pipelines with multiple stages. Together, these results provide a simple and efficient training paradigm for LLM agents to extract, refine, and reuse transferable skills across tasks.

## 方法论
- **核心思想**：将一组相关任务实例组织成“渐进困难”的序列，用一个共享策略交替执行两种行为——**任务求解** 和 **技能文档策划**。任务求解依赖上一轮技能文档的指导，策划则根据当前任务的轨迹与结果对技能文档进行改写，并将其作为唯一信息通道传递给下一个任务。通过解耦的跨任务信用分配，使两种行为接受与自身时序角色对应的学习信号，从而让智能体逐步学会生产可迁移的技能并有效利用。

- **关键技术与流程**（见图1概述）：
  - **跨任务序列构建**（Cross-Task Sequence Construction）  
    给定一个任务族（environment-provided family metadata），将其中的任务实例按难度递增排序（例如 WebShop 中按所需属性与选项数量排序），组成长度为 \(K\) 的序列。不同实例目标与实体不同，但共享底层交互流程。
  - **带技能演化的序列式交互**（Rollout with Skill Evolution）  
    每个序列开始时技能文档 \(S_0 = \emptyset\)。对第 \(i\) 个任务：  
    - 基于前一技能文档 \(S_{i-1}\) 生成求解轨迹 \(\tau_i\)，得到即时任务奖励 \(r_i\)。  
    - 对于 \(i<K\)，同一策略从求解切换至策划，根据当前 \(S_{i-1}\)、轨迹 \(\tau_i\) 和结果 \(r_i\) 生成修订后的文档 \(S_i\)。  
    文档改写规则：保留有用技能，将具体实例信息泛化为一般概念（如“目标对象”），提炼成功步骤或失败陷阱，产生可跨实例迁移的工作流。
  - **解耦信用分配与分组优化**（Decoupled Credit Assignment & Group-relative Optimization）  
    - **解耦回报**：求解阶段的回报 \(G_{i,\text{solve}} = r_i\)；策划阶段的回报为折扣后的下游任务奖励之和 \(G_{i,\text{curate}} = \sum_{j=i+1}^{K} \gamma^{j-i} r_j\)（\(\gamma\) 跨任务折扣因子）。这将对当前任务的执行评价与对技能迁移质量的评价分开。  
    - **分组相对优势**：对同一序列、同一任务位置 \(i\) 和同一角色（solve / curate）的 \(N\) 个独立实验，计算组内平均回报作为基线，得到分组优势 \(A^{(n)}_{i,z} = G^{(n)}_{i,z} - \bar{G}_{i,z}\)。  
    - **优化目标**：采用类似PPO的clipped目标，将角色级别优势应用于对应生成token，联合优化求解与策划行为。

## 主要结论与发现
- SkillRise在所有三个基准上均取得最优Pass@1结果，相对最强基线提升幅度为2.3~8.5个百分点（ScienceWorld上提升8.5）。
- 由跨任务训练得到的技能策划策略能够直接泛化到同任务重复尝试中，Pass@2/3同样最优，甚至超越了专门为此设计的LaMer（ScienceWorld Pass@3高出14.2点）。
- 在测试时，随着相关任务序列长度增加（K从2增至6），SkillRise性能单调上升，而其他RL方法未见持续提升，证实了“可迁移技能复用”而非“重复采样收益”。
- 在保持强性能的同时，SkillRise端到端设计的运行时间仅为RetroAgent的1/6、SkillRL的1/4.3，大幅降低了技能学习管线的计算开销。
- 解耦信用分配对超参数 \(\gamma\) 不敏感，方法稳健；消融实验表明丢弃技能策划会使效果明显下降，验证了策划行为的必要性。

## 优点

- **时序对齐的解耦信用**：任务求解与技能策划分别受当前奖励与未来奖励监督，信号清晰，避免了多阶段流水线中责任混淆的问题。
- **强大的跨任务扩展能力**：所学的技能文档能在长序列中持续改进，证明了真正意义上的可迁移知识积累。
- **训练效率突出**：在不牺牲精度甚至提升性能的前提下，运行成本大幅降低，对实际部署极为友好。
