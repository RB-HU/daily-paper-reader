## 摘要
强化学习使智能体式检索增强生成系统能从可验证的结果奖励中学习多轮搜索，但全零展开组不提供比较信号，可能隐藏有用的搜索行为。我们提出EviBack，一种证据约束的教师回退方法，为此类组提供辅助监督，同时保留可验证的Actor奖励。它将证据评估与答案精炼分离，防止参考答案覆盖证据不足的判断。全自动端到端的GPT-5.5辅助自动提示工程流水线从人工编写的单提示双任务教师开始，自动划分和标注展开数据，并进行消融、任务分解、评估和选择，生成门控的两阶段教师。与人工设计相比，生成的教师提高了下游F1值和有效答案率，同时减少了搜索、重复查询和强制终止。在七个开放域问答基准和三个Qwen3规模上，EviBack相比Search-R1提高了F1值，并提升了单跳和多跳宏F1。我们保证代码将在后续阶段公开发布。

## Abstract
Reinforcement learning enables Agentic RAG systems to learn multi-turn search from verifiable outcome rewards, but all- zero rollout groups provide no comparative signal and may hide useful search behavior. We present EviBack, an evidence- constrained Teacher backoff that supplies auxiliary super- vision to such groups while preserving verifiable Actor re- wards. It separates evidence assessment from answer refine- ment, preventing reference answers from overriding evidence- insufficiency judgments. A fully automated, end-to-end GPT- 5.5-assisted APE pipeline starts from a manually authored single-prompt dual-task Teacher, automatically partitions and labels rollout data, and performs ablation, task decomposition, evaluation, and selection to produce a gated two-stage Teacher. Compared with the manual design, the resulting Teacher im- proves downstream F1 and valid-answer rate while reduc- ing search, duplicate queries, and forced termination. Across seven open-domain QA benchmarks and three Qwen3 scales, EviBack improves F1 over Search-R1 and raises both single- and multi-hop macro F1. We guarantee that the code will be made publicly available at a later stage.

### 2. 论文提出的方法论

EviBack的核心是在强化学习训练中引入一个证据约束的、两阶段的“教师”策略，仅在Actor完全失败时提供弱化的辅助奖励。

*   **核心思想：证据约束的教师回退**
    *   **Actor优先**：只有当一组8条采样轨迹均未匹配正确答案时，才激活“教师”模型提供辅助奖励。有正确答案的组仍使用原始的可验证奖励。
    *   **证据边界保存**：教师模型的核心是分离“证据评估”与“答案精炼”，坚决防止参考答案（黄金答案）说服模型在证据不足时强行产出答案。
*   **关键技术细节：两阶段教师策略**
    *   **第一阶段：证据状态评估**：一个“盲”阶段，教师仅根据问题和Agent可见的搜索证据 (`Ei`) 判断当前证据状态，并输出一个XML格式的标签：
        *   `Supported （S）`：证据足以支撑一个完整答案。
        *   `Insufficient （I）`：缺少关键事实或推理链条。
        *   `Ambiguous （A）`：存在多个不兼容的可能答案。
    *   **第二阶段：答案精炼**：仅当第一阶段状态为`S`或`A`（非`I`）时激活。教师接触参考答案进行精炼，但有一个不可逾越的**门控机制**：只要第一阶段判为`I`，最终状态必须是`I`，杜绝参考答案的逆向覆盖。
*   **算法流程：Actor优先的回退奖励**
    1.  Actor对问题采多轨迹。
    2.  若任轨迹答案与参考答案匹配，则该组奖励保持为原始二元奖励。
    3.  若全组失败，则调用冻结的两阶段教师模型为每条轨迹生成辅助奖励`ri`：
        `ri = β * 1[sfinal ≠ I] + γ * 1[ci] * F1(ŷi， g)`
        其中`β， γ = 0.1`，这赋予“非证据不足”的轨迹一个基础奖励，并对其中的有效答案按参考答案F1进行排名。
    4.  对全零奖励组内的奖励进行标准化，并乘以一个衰减因子`λ = 0.1`，降低其对策略梯度更新的影响。
*   **教师模型的自动构建**
    *   使用名为**E2E-APE**的自动流水线，由GPT-5.5作为控制器。它从一个手工编写的单提示双任务教师开始，自动对采样轨迹进行划分和S/I/A标注，然后通过消融、任务分解、评估和选择实验，自动生成最优的门控两阶段教师提示词和工作流，并最终冻结。
